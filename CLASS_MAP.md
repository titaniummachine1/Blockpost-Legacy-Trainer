# Blockpost Legacy — Comprehensive Class Map

Static analysis of all 5360 types in `dump.cs`. This document maps every
important game class, its obfuscated name, purpose, key fields, and key
methods.

Generated by `Tools/dump_analyzer.py`, `Tools/auto_alias.py`, and manual
inspection via `Tools/inspect_class.py`. The SDK now covers 278 aliased
classes, including the full `Client`/`Network` packet pipeline
(`SendHitReport`, `ProcessPacket`, `Flush`) and all referenced Unity/engine
types.

## 7. Tooling

| Tool | Purpose |

| `Tools/generate_sdk.py` | Generate C# SDK from dump + aliases |
| `Tools/auto_alias.py` | Auto-generate aliases for all target classes |
| `Tools/inspect_class.py` | Inspect a specific class in detail |

| `Tools/extract_strings.py` | Extract string literals from dump |
| `Tools/map_net.py` | Map NET protocol primitives by signature |
| `Tools/find_readable.py` | Find classes with readable field names |

Usage:
```bash
python Tools/dump_analyzer.py     # Build type database
python Tools/auto_alias.py        # Generate aliases
python Tools/generate_sdk.py      # Generate SDK
python Tools/inspect_class.py ClassName  # Inspect a class
dotnet build                      # Build + deploy
```
